# Créditos

Projeto pessoal de estudo, sem fins comerciais. Pokémon e todos os personagens, nomes e modelos
© Nintendo / Game Freak / The Pokémon Company. Este projeto não é afiliado a elas.

## Jogo 3D
- **Modelos 3D** (`jogo-3d/modelos/`, `assets-originais/glb/`): projeto **Pokemon-3D** de Sudhanshu Ambastha
  (https://github.com/Sudhanshu-Ambastha/Pokemon-3D). O código do projeto é MIT; os modelos em si são
  propriedade da The Pokémon Company e foram reunidos de coleções do Sketchfab
  (https://sketchfab.com/SudhanshuAmbastha/collections), onde estão os créditos de cada artista.
  O próprio projeto diz que é para uso educacional e não comercial.
- **Sprites de efeitos** (`jogo-3d/efeitos-originais/`): Pokémon Showdown client (https://github.com/smogon/pokemon-showdown-client),
  pasta `play.pokemonshowdown.com/fx`. Os demais efeitos são desenhados por código neste projeto.
- **Compressão dos modelos**: glTF-Transform (MIT) + meshoptimizer (MIT).
- **three.js r149** (MIT) — https://threejs.org — em `jogo-3d/js/lib/` (empacotado com esbuild), incluindo
  EffectComposer, UnrealBloomPass e GammaCorrectionShader (pós-processamento).
- Mapas, clima, Ultimates, músicas e sons da V8: feitos por código neste projeto.
- **Ícones dos Pokémon**: PokeAPI (https://github.com/PokeAPI/sprites).

## Jogo 2D
- **Sprites de batalha (8 direções)**: PMD Sprite Collab — https://sprites.pmdcollab.org — licença CC BY-NC 4.0.
- **Sprites e ícones do menu**: PokeAPI / Pokémon Showdown.
- Cenários, efeitos e sons: desenhados/sintetizados por código neste projeto.
